# Warehouse administration UI

The current product uses the RuoYi Vue 3 shell and Element Plus. Warehouse and finance staff work through data tables and labelled forms; new screens should use the existing theme and density.

- Inherit Element Plus semantic colors and the existing application theme. Do not introduce a separate palette or display font.
- Use the existing app-container, tabs, descriptions, tables, drawers and confirmation dialogs.
- Use regular system typography; finance page titles are 20px, section titles 16px.
- Use 16–20px between related sections. Keep action buttons next to the operation they affect.
- On narrow screens, wrap forms and actions and allow tables to scroll inside their own bounds.
- Preserve visible loading, disabled, empty, error and unresolved-request states.
- Use the existing bilingual helper for new customer-visible copy.
