# 若依迁移状态

当前项目只保留若依 Vue 3 和 Java 后端。本页区分已经接通的 Java 业务和仍待实现的原系统功能；删除旧源码不代表完成这些功能。页面目录中有 69 类业务字段定义，不代表 69 类业务都已迁移。

完整替换目标及各项验收门槛见 [现有系统完整替换验收](REPLACEMENT_ACCEPTANCE.md)。目标持续有效，模块完成记录不等同于整体替换完成。

## 当前结构

- 管理后台：`admin-ui`，若依官方 Vue 3、Element Plus、Pinia 和动态菜单。
- 后端服务：`backend`，若依 Spring Boot 3 分支、Java 17、MySQL 和 Redis。
- 旧 Node / SQLite 应用、旧前端和根目录启动入口已移除。Node.js / npm 继续用于 `admin-ui` 开发与构建，Java 业务不依赖它们。
- 当前仓库：`cangchu-backend`、`cangchu-admin` 与 `cangchu-warehouse`，默认分支均为 `main`。此前开发记录中的迁移分支名仅用于说明历史阶段。本阶段不替换生产服务，也不自动导入旧数据库。

## 本次新增：扫码拣货与多箱装箱（2026-11-16）

## 本次新增：库存盘点与差异调整（2026-11-16）

新增双语盘点页面及 `/warehouse/stocktakes` Java API。盘点单固定一个客户、一个仓库和 1–100 个库位，建立时冻结此客户的对应库位并保存原库存快照。冻结同时覆盖空库位，防止盘点中途新建库存池；手工增减/移库、ASN 收货、订单拣货发货与预留释放检查同一冻结记录，订单分配可使用其他未冻结库位。盘点期间不能更改库位归属或用途。库存页标记盘点冻结，可用数量暂为零，原实物与预留数量不变。

支持逐行实盘、差异原因、补录账面外的批次/串号货物、提交复核、退回清空实盘并保留证据、审核调整和取消解冻。未填写与明确盘为零是不同状态。普通复核人不能是本单创建者或参与盘点者；管理员自审必须明确勾选并填写原因，保留审计。盘亏不得扣掉已分配订单的库存，盘盈检查容量和串号唯一性并建立当前发现时间的库存来源层，不伪造历史收货日期。

审核按先盘亏、后盘盈处理，库存、来源层、流水、行结果、审计、审批状态和解冻共同提交；失败时原库存和冻结保留。取消不改库存，即使客户策略后来变化也能解除原冻结。相关表和权限来自 `warehouse_011_stocktake.sql`、`warehouse_012_stocktake_menu.sql`，需先迁移再升级业务服务。正常盘点每单最多 2000 行，每次保存 200 行；保管/隔离库存及盲盘模式尚未实现。

本轮使用本地合成库存；新 SQL、测试数据、服务重启和失败测试的取消清理均在隔离环境执行，原 Mintsoft 与部署中的生产系统未改动。盘点功能通过本地验证不代表已经完成第三方联调、真实数据迁移或全系统切换。

## 本次新增：客户退货、隔离检验与处置（2026-11-16）

新增原生 Java `/warehouse/returns` 与双语退货页面。一单关联原发运中的一个商品；登记时占用原发运可退额度，收货时逐笔选择实际发货来源。并发退货单、重复收货以及多单累计退货都不能超出原发货量。未收货可取消；已收货必须先处置隔离余量再结案，短收需要管理员明确确认。

实物先入带保管标记的 Quarantine 库位，可售数量为零；不生成可被普通订单分配的库存。检验后按权限分别执行上架或报废，允许分批处置。原入库时间、来源、批次、串号和效期保持可追溯；检验通过本身不改变可售库存。上架会检查库位盘点冻结、容量、串号冲突、商品/仓库规则和效期策略。商品策略优先于客户策略；禁止过期会拦截上架，提醒策略保留过期警示。库位归属和隔离分类不能在有库存时随意改变。

退货费在登记时保存商品覆盖客户的首件、续件价格快照，明确零价有效；缺失价格不会默认为免费。分批收货仅收一次首件费，并使用累计金额差额避免分批舍入漂移。库存、费用、审计和请求编号共同提交，丢响应后可刷新并重试原请求。正常仓库角色不能通过退货详情、通用读接口或重试查看财务价格；签收、检验、上架、报废、结案各有独立权限。

## 本次新增：历史仓储计费与库位价格（2026-11-16）

新增仓储历史记录、历史库存查询、库位仓储单价和仓储周期结算。先应用 `warehouse_015_storage_history.sql`，由管理员在财务页面启用记录，保存当时主数据和库存来源基线。此后原生库存与相关价格修改按业务事务记录最终状态；移库不会把事务中途状态当成额外占用峰值。入库、手工增减、盘点、发货和退货共用记录入口，只有预留变化时不新增实物历史。记录失败时原业务一并回滚。
